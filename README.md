# 壁近傍だけにTCIを用いるLBM研究の概要

更新日：2026-10-05

壁近傍の細格子帯をTensor Train（TT）で保持し、Tensor Cross Interpolation（TCI）で必要な分布関数値を取得・近似する研究。対象はD3Q27・BGK衝突の平行平板流れで、中央の粗格子は密配列、壁帯は圧縮表現で扱う。

最新のN128・4モード試験では、重複する受理検査の共有によりTCI側の32更新時間がCで約10%、Bで約15%短縮した。**共有後のTCI/dense時間比はC 2.407、B 1.629。今回の条件ではdenseが速く、TCI速度優位は未確認である。** 過去には別の精度・計時契約でTCIが速いN128結果も得られているが、現在の結果とは分けて読む必要がある。

本書は保存された研究記録から主要な到達点をまとめたもの。用途は他エージェントによる研究の立ち位置と方向性のレビューである。研究全体の履歴、ソースコード、実験データ、実行ログは含まない。

## 研究の狙いと評価の考え方

壁帯の低ランク性を利用して、密配列による細格子更新の費用を減らす。評価対象は圧縮容量だけでなく、構築に必要な取得点・要求回数、衝突と壁境界の精度、累積軌道誤差、初期構築と失敗候補を含む実時間である。

初期の圧縮比較120条件では、全点監査に合格したものが46件、計算終了後に精度不合格となったものが65件、例外・資源条件による停止が9件あった。約23倍に圧縮できた壁帯でも、異なる格子点の94.5%を取得し、重複込みの評価数が全格子点数の3.55倍になった例がある。**低ランクで保持できること、少数点で構築できること、速く更新できることは、それぞれ確認が必要である。** TCI内部の収束表示を全域精度の保証には使っていない。

同一入力に対する一更新の比較と、異なる近似状態を経由して進む累積軌道の比較を分ける。速度比とともに実秒、対照denseの実秒、反復数、計時に含む処理を示す。途中で停止した条件や、比較基準が変動した結果を成功した高速化に読み替えない。

## 取り組みの流れ

| 段階 | 主な取り組みと到達点 |
|---|---|

| 履歴の再利用 | 直前の代表点を使う固定クロスを基準とし、棄却された場合に再探索・warm修復を行う。再利用した添字でも現在の入力値を取得し、受理判定を行う。 |
| split-q配置 | 衝突後の分布をTTコアと明示的な境界平面で保持し、streaming・reflectionをコア操作と平面操作で扱う構成へ進んだ。帯単独・既知ghost面による試験を、初期の粗密閉ループ方式から分離した。 |

## 壁面補正と厳しいguardが解決したこと

2026-10-01の旧v4試験では、4モードN64・16細ステップで壁面補正によりtwo-siteへの戻りが8回から0回になった。更新時間総和は約10.515秒から2.574秒、当時のTCI/dense総時間比は約19.775から4.215へ下がった。一方、受理された固定更新の中央値は61.1msから90.3msへ増えており、壁面補正自体の費用が残った。

1モードN64・128細ステップでは、population guardを1e-7にすると、衝突fitが当時の全場許容値1e-7を超えた更新が6回から0回になった。総時間比1.159→1.045だけを高速化の証拠にはしていない。TCI実時間は4.950987→4.981558秒、denseは4.272761→4.767990秒で、比較基準側も変動していた。

補正で同じ入力の壁面値を局所的に厳密にしても、近似状態を積み重ねる軌道の誤差は残る。旧v4結果には現在の累積速度・壁せん断基準を超えるケースがあり、現行契約の精度合格には転用しない。単純な1モードで壁面補正が費用だけを増やした観測も踏まえ、補正の共有縮約と適用条件を検討してきた。

## 現在の構成と受理条件

現在はN128の細格子帯128×32×128を対象とする。4モード、phase0、force0、準備時刻t=0.0625、細刻み1/256、緩和時間2.036、32細更新後のt=0.1875。同じ物理帯・同じghost列のdenseを対照に使う。

外力なしのBGK更新は `f_q*=(1−1/τ)f_q+(1/τ)f_q^eq(ρ,u)`、`ρ=Σq f_q`、`j=Σq c_q f_q`、`u=j/ρ`。全TT・境界項を合わせた同じ入力からmomentを求める。平衡分布の非線形二次項 `Q=jj^T/ρ` が構築費用と次候補の焦点の一つである。streamingは方向ごとの格子移動、壁はreflection、外側面は既知ghostで扱う。

- **C方式**：壁面を明示的に補正し、補正を衝突後・streaming/reflection前に適用する。
- **B方式**：下側2層をdenseで更新し、その外側をTTで保持する。TT部分の座標offsetは2。
- **衝突構築**：履歴の代表点によるfixed候補を試し、許可された棄却に対して最大1回のwarmへ進む。failed fixedとwarmの費用を両方計上する。
- **検査点**：構築から除外するS_f/S_w/H各256点を予約し、全27方向を扱う。Hは現在入力から一回fresh評価し、構築・選択の結果を再利用しない。この独立性は同一更新内の役割分離であり、時刻間の独立標本を意味しない。
- **数値基準**：fit 1e-8、重要面・検査のpopulation 1e-7、Fのvelocity 2e-5・stress 5e-3。累積velocity 2e-5・壁shear 1e-4、ledger 1e-9、初回kernel 1e-14を維持する。P/Hの派生速度・stressは、誤差閾値の有無と別にfinite判定に関わる。
- **失敗処理**：solver受理と研究正式受理を分け、後段の研究・登録不合格もrollbackして停止する。非有限、検査不能、精度・資源不合格を合格へ読み替えない。

誤差は各検査の対象点・面について、非加重の相対L2で定義する。`e_f=||f_obs−f_ref||₂/max(||f_ref||₂,1e-30)` は全27方向、`e_u=||u_obs−u_ref||₂/max(||u_ref||₂,1e-30)` は全3速度成分。非平衡応力は `Π^neq=Σq c_q c_q^T(f_q−f_q^eq)`、その相対誤差は対象点と全tensor成分を平坦化したnormの比である。現契約では応力参照norm≤1e-14を相対誤差0として扱い、絶対誤差とfiniteを別に記録する。この小参照norm域でstress許容値が絶対誤差を制約する保証はない。P/Hの誤差拒否はpopulationのみで、速度・応力のfiniteは残る。fit 1e-8は構築targetであり、内部収束だけで全域精度を保証しない。

局所一更新の研究誤差は同じ現在TT入力を厳密に衝突・輸送した参照との比較、累積誤差は独立に時間発展したdense軌道との比較。壁shearは下壁での衝突・反射による局所運動量交換のx成分を壁面fieldとして相対L2で比較する。ledger 1e-9は輸送収支の絶対判定、kernel 1e-14は初回の凍結一更新の代数照合であり、どちらも上記の相対誤差と同じ指標ではない。

資源上限はrank48・最大4cycles、局所workspace512MiB、RSS1280MiB、空きRAM floor512MiB＋reserve128MiB等を使用する。取得の固有点上限と重複込みscalar要求予算は別に扱う。過去のsampling・RAM・診断RSS停止を残し、必要な資源契約の変更は別登録で実施した。全点診断のchunk化は、数式・対象全点・閾値を維持した変更である。

## 採用・不採用・保留の判断

| 案 | 現在の判断と理由 |

| 現在入力のコア共有縮約、署名期待表の再利用、unique scalar要求 | 登録した入力・経路で費用低下と同等性を確認し限定採用。一般入力・将来のpivot不変・長期性能へは一般化しない。 |
| 最終Fと同一P面の共有 | 最新N128比較で限定採用。H独立性と残る検査を維持し、第二経路の故障検出が減る点を明記した。 |
| H2平面評価の試作 | 保存Fに対する厳密scalar互換条件が不合格となり停止。後続の再現性診断でも根因未確定で、現行基準へ統合していない。 |

## 未検証事項と次候補

最新の共有比較は、同じ代表入力の時間反復と各条件1軌道に限る。全32更新の全域F/P/stream診断、数学的な点別誤差・正population保証、別位相・外力・初期場、自然warmを含む長期、発達乱流での実用性能は未確認。既知ghostによる帯単独試験であり、**現行split-qのTT粗密閉ループは未検証**。局所的に厳密な補正や衝突moment保存から、累積軌道や投影・stream後の保存を自動保証しない。

以下は現在検討している未実行の候補例である。レビューで提案する方向はこれらへ限定しない。

1. **B密2層の独立照合とledgerの所属を分ける。** population配列だけでなくrho除算後の速度、非平衡stress、norm等のfiniteを残す範囲を定義する。独立BGK人口1e-7拒否とledger1e-9拒否をsolverから外せば、参照・差分・収支由来のfiniteや毎更新故障の検出も失う。研究側の確認頻度は未確定で、従来の毎更新正式受理を保つには研究側でも毎更新照合とrollbackが必要。ledgerの和を省きながら同じoverflow拒否を保証することはできない。
2. **部分線形化と凍結基底への直接縮約を一入力で検討する。** 現在の全sourceからU(y)を作り、u0=U(y)e_xとして、Q=jj^T/rhoを厳密線形部とR=rho(u−u0)(u−u0)^Tへ分ける。直前の受理Fだけで選ぶ基底へ各項を直接投影し、大きなTT和とroundを避ける案。R省略は二次momentを変える別モデル近似で、未検証の実績には数えない。
3. **費用・誤差の棄却条件を先に固定する。** R取得/fitを楽観的に無料とした構成費用に、維持する検査・stream・historyを足しても共有後Bの同入力・同範囲費用以上なら停止する。基底外誤差またはR省略誤差が元F由来の絶対予算・既存物理基準を超えれば停止する。正密度・非零U・全速度成分を含む厳密分割の小代数照合が初回kernel基準に合わない場合も進めない。残差fitの相対分母を変えて元Fの誤差制約を緩めず、rank・取得・一時容量と次更新費用まで確認してから拡張する。

新保存量補正、粗密接続、複数時刻の基底再利用をこれらの初期試験へ同時に導入する計画ではない。基準を結果後に緩めず、効果がなければ次段階へ拡張しない。

## 方向性レビューで判断してほしいこと

1. 現精度契約と必要検査を維持した場合、denseとの差を減らす見込みが最も大きい方向は何か。壁近傍TCIが有望になる流れ・格子・精度条件も示してほしい。
2. 観測した局所的な費用削減を続けるべきか、表現・構築・計算法を変えるべきか、モデル近似を検討すべきか。どの費用をどこまで減らせると考えるか、未検証の仮定と分けて判断してほしい。
3. 各提案を反証できる最小の観測・比較は何か。単一保存状態で棄却できるもの、累積軌道・壁/粗密接続まで必要なものを区別し、停止条件を先に示してほしい。

提案ごとに「局所改善」「計算法・表現変更」「モデル変更」「精度・保証変更」を区別する。許容値の緩和、finite範囲の縮小、検査の間引き・免除、独立性や保存量拒否の撤去に依存する案は、その変更と失う保証を明示してほしい。小振幅・低rank・正密度等の成立条件も、現在確認済みか仮説かを分ける。本書の段階名・H2等は元研究内の呼称で、詳細記録や実装がこの共有資料から閲覧できるとは仮定しない。

**有望な方向を優先順位付きで提案し、期待効果・成立条件・反証できる最小試験を示す。実装不要。**
