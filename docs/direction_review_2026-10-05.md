## 0. 要約

- **fixed 更新に限れば、構築側の費用は dense の約半分で、TCI 時間の 6〜7 割は検査区間である。** fixed31 の TCI/dense は C 1.90、B 1.14。cold 1回は C 12.7 秒、B 11.9 秒で、dense 1更新の約17倍。現条件で dense が速いという主結論は変わらない。
- **現行 paired 配置の合成場 rank は実測と同規模である。** 合成場で paired 配置の rank は 25/12（擾乱 27%）、実測は 25/17（C）。合成診断は仮説の篩として使える範囲にある。
- **R項だけを cross で取得する部分線形化は、節約が凍結基底への投影でのみ生じる。** fiber 評価経路では線形部の評価費用が現行と同じになり節約がない。凍結基底が次の完全 target を予算内で表せるかは未検証で、せん断による位相の y 依存化は毎更新新しい方向を生むため、失敗の可能性が高い機構がある。試験は保存状態で安価に行える。
- **配置については、合成場で q を末尾に置く4コア配置が現行 paired の約 1/5 の要素数、paired のまま xyz 順が約 1/2 だった。** 後者は README の cut 診断と符号が一致する。前者は streaming の局所性と引き換えで、保存 F での要素数・stream 費用・pivot 継承の比較が先。
- **検査費用は面評価が主で、1面の演算量下限は数十 Mflop 規模である。** 実測の source 72.6 ms、candidate 63.8 ms との差が何に由来するかは、同条件の処理列計時で切り分ける。差の全部を管理費とはみなさない。
- **領域試験（1モード、N256）は単一状態試験の後に置く。** N256 は配列容量だけでなく取得経路と workspace の資源入場を別に確認する。
- **R 省略は合成場では現契約と両立しなかった。** 実保存入力での確認は単一状態で行える。

現行は 3 paired core で、重複込み scalar 要求は次式。H は fit 対象の帯厚で C 32、B 30。

|---|---:|---:|
| bulk rank r₁ / r₂ | 25 / 17 | 25 / 16 |
| fit の raw scalar 要求 | 175,346 | 165,521 |

- raw 要求は dense の population 数 14,155,776 の 1.24%（C）。固有空間点は全格子点の 9.2%（C）、6.7%（B）。
- fixed 1更新の差引残 0.33〜0.37 秒を raw 要求数で割ると 1要求あたり約 2 μs で、dense の 1 population 更新（約 50 ns）の約 40 倍。差引残には取得以外も含むので上限値だが、取得費用が「点数 × 小さな定数」ではないことを示す。1要求あたりの費用の内訳が提案1の対象。
- N_raw の主項 3N_z r₁r₂ を dense で割ると r₁r₂/(9N_xN_y)。この式では N_z は相殺し、N_x と N_y と rank だけが比を決める。N256（N_x=N_z=256、rank 同じ）なら 0.61%、rank 10/8 なら 0.25%。これは要求数の比であり、費用比ではない。

### 1.3 有望条件の目安（仮説）

初版の余裕係数は 4コア配置を前提にしていたので取り下げる。現行配置では要求数比 r₁r₂/(9N_xN_y) が目安になるが、1要求あたりの費用、検査の面数、cold・warm の頻度が同程度に効くため、採否基準にはしない。面内 N の増加と rank の低下が有利に働く方向性のみを仮説として残す。旧 N128 優位と現結果は入力場・精度・検査・計算範囲が同時に異なるため、「領域差が主因」とは分離できていない。

### 1.4 dense 基準の水準

dense は 1更新約 0.69 秒で、2千万 population/秒程度。最適化された実装はこの 1 桁上を出し得るが、同条件の実測はない。最終的な優位の主張は格子規模または 1/rank に対する漸近的なものに限られる、という方針は維持する。

## 2. 合成場による TT 診断（改訂2で再実行）

### 2.1 目的と限界

スクリプト `scripts/toy_tt_rank_check.py`、生データ `docs/toy_tt_rank_results.json`。改訂2で (a) 現行 paired 配置を比較基準に追加、(b) 全 TT-SVD の再構成誤差を記録、(c) R 項の予算を 1/2・1/4・1/10 に割った感度を追加した。全 TT-SVD の達成誤差は ‖f*‖ 基準で 7.5e-9 以下。

- 格子：128×32×128、D3Q27、BGK τ=2.036。帯は下壁から32層。
- 場：平均流 U(y) は半チャネル高さ128の放物線で U_max=0.05。擾乱は (k_x,k_z)=(1,1),(2,1),(1,2),(3,2) の4モード、phase 0、壁で消える y 形状。振幅は u'/U の rms が 2.7%〜540%。
- 分布：f = f_eq + f_neq（Chapman–Enskog 一次）、f* = (1−1/τ)f + (1/τ)f_eq。
- 計測：TT-SVD で絶対予算 1e-8·‖f*‖ まで逐次打ち切った rank・要素数・raw 代理値（要素数 + 内部 bond の r²。paired では 1.2 節の式に一致）。

**限界。** 元研究の場ではない。TT-SVD の逐次打ち切りは準最適で、TCI の rank 下限ではない。壁面補正・境界項・streaming・時間発展・計時は含まない。合成場の非平衡は一次 Chapman–Enskog で、方向成分は {w, w c_α, w c_α c_β} の張る10次元部分空間に入る。実際の source にはより高次の方向成分があり得る。

## 3. 優先順位付き提案

技術回答 4 節の順序に従う。各提案に分類、内容、期待効果、成立条件（確認済み／仮説）、最小の反証試験と停止条件、必要な試験規模を示す。

### 提案1：保存記録の整理と費用の下限分解

- **分類**：診断。既存ログだけで完了する。
- **内容**：(a) 現行配置、raw/固有/dense 台帳、cold/fixed、F/P/H の対象を文書上で訂正する（本版で着手）。(b) 保存 step2 入力 1 件で、fixed 更新 1 回の差引残 0.33〜0.37 秒を、入力 source の fiber 評価、補間・skeleton 更新、補正、stream/reflection、history に分け、各項の演算量を rank と辺長から見積って実秒と並べる。
- **期待効果**：直接の高速化はない。1 要求あたり約 2 μs（上限）の内訳が分かり、提案2〜4 の採否と期待値が決まる。
- **停止条件**：なし。
- **規模**：単一保存状態。

### 提案2：同契約の検査処理列の計時と共有

- **分類**：局所改善。数式・対象点・面数・頻度・独立性は不変。
- **内容**：保存 step2 で source 評価、BGK 参照、candidate 評価、metric、管理処理を分けて計時する。技術回答の C 上面の子計時は source 72.61 ms、BGK 10.59 ms、candidate 63.84 ms、metric 31.50 ms、計 178.5 ms で、C 3 面・B 2 面に S_f を加えると実測の F 区間（C 0.57 秒、B 0.35 秒/更新）と整合する。
- **演算量の参照値**：paired 配置 rank 25/17 で y 面 1 枚を TT から評価する演算量は、core3 の面スライスを core2 に縮約してから core1 と積を取る順で約 23 Mflop、BLAS では数 ms 規模。source・candidate の実測 64〜73 ms との差が、境界項・補正・offset 処理・経路の一般性のどれに由来するかを処理列計時で切り分ける。差の全部を管理費とみなさず、BGK 10.6 ms だけを下限ともみなさない。
- **期待効果**：検査区間は fixed31 の TCI 時間の 59%（B）〜72%（C）を占めるので、面評価が演算量に近づけば効果は大きい。ただし削減可能な幅は処理列計時の結果で決まり、ここでは見込みを数値化しない。
- **成立条件**：source・candidate の実測と演算量の差が、契約を変えずに縮められる処理に由来すること（仮説）。
- **停止条件**：処理列計時で、差の大半が維持すべき処理（境界項の合成、finite 判定、独立再計算）に由来するなら、この提案の期待値を下げ、提案3・4へ重みを移す。初版の「3 以下／5 倍以上」という定数は使わない。
- **規模**：単一保存状態。削減後は受理値・finite 判定・例外・offset・最終候補の所属が一致することを同じ入力で確認する。

### 提案3：部分線形化と凍結基底への直接投影

- **分類**：計算法変更。モデル不変、契約不変。README の候補2。
- **代数**：正密度のもとで Q = jjᵀ/ρ = −ρu₀u₀ᵀ + u₀jᵀ + ju₀ᵀ + R、R = ρ(u−u₀)(u−u₀)ᵀ、u₀ = U(y)e_x。U ≠ 0 は恒等式の条件ではない。R の population 寄与は D_q = (1/τ) w_q (4.5 c_qc_qᵀ:R − 1.5 tr R)。moment は TT 本体と明示的境界項を合わせた source から求める。
- **節約が生じる経路**：線形部の各項（ρ、j_α、U(y) スケーリング）は個別には rank 保存の縮約で作れるが、和は各項の rank を超え得る。節約が生じるのは、和を形成せずに前回受理 F の左右基底 B へ各項を直接投影し、Σn·r²·項数 規模の縮約で済ませる場合だけである。線形部を fiber 上で評価する経路では、1 点の評価費用が現行の source 評価と同じになり節約がない。
- **期待効果**：点取得が R 項の cross に限られる。合成場では現行配置で f* の 12〜20% の raw 代理値（2.2 節）。実 TCI の固有取得数・棄却経路・準備費・計時は未検証で、費用倍率は見込みとして述べない。
- **成立条件**：
  - 凍結基底 B が次の完全 target F_exact を予算内で表せる：**未検証の仮説**。fixed31 はこれを示さない。せん断流では擾乱の位相が y に依存して進むため、各更新で前回基底に含まれない方向が一次で生じ得る。失敗する可能性が高い機構として先に認識しておく。
  - R の rank が f* より十分小さい：合成場で支持、実場では仮説。
  - 正密度：現場で確認済み。
  - 投影・縮約・丸めの一時容量と費用が現行の取得費用を下回る：見積りのみ。
- **誤差予算**：同じ非加重 Frobenius norm で、E_outside + E_Dfit + E_contraction + E_round ≤ ε_fit‖F_exact‖ を満たすよう配分する。各項に全予算を独立に与えない。合成場では D の予算を 1/10 にしても raw 代理値の増加は 35% 以内（2.2 節）。F の population・速度・応力、P/H の population と派生量の finite、累積速度・壁 shear は既存基準で別に確認する。
- **最小反証試験（単一保存状態、順に）**：
  1. 保存入力から D を厳密に計算し、‖D‖/‖F_exact‖ と、配分後の予算で TT-SVD した rank・raw 代理値を記録する。D の raw 代理値が現行 fit の raw 要求の 0.5 倍を超えるなら、構築費用の門（4）で停止する可能性が高いので先に報告する。
  2. 前回受理 F だけから基底 B を選び、次の完全 target に対して ‖F_exact − P_B F_exact‖ を測る。基底選択に次 target を使わない。配分した E_outside を超えれば、この凍結基底案を停止する。
  3. 分割の代数照合を kernel 1e-14 で行う。比較する出力・norm・演算順を固定し、既存 C の round による差と新しい全中間量への要求を区別する。
  4. D の取得・fit を無料とした構成費用に、維持する検査・補正・stream・history・次 skeleton を加えても、共有後 B の同入力・同範囲費用以上なら停止する。
- **試験 2 が失敗した場合の派生案**：基底を前回 F だけでなく、前回の D-cross の fiber や直前 2 更新の差分方向で拡張する。拡張の費用と基底外誤差を同じ予算で再評価し、現行 fixed cross を fallback とする候補列（新候補 → fixed → warm）として費用を計上する。失敗候補の費用は両方計上する。
- **規模**：単一保存状態で 4 試験。合格した案一つを提案5へ。

### 提案4：配置の単一状態比較

- **分類**：表現変更。厳密、契約不変。
- **内容**：同じ保存 F、同じ絶対予算で、現行 paired、paired xyz、6 コア分離、[x,z,y,q] の要素数・全 bond rank・raw 代理値を比べる。合成場では現行比で xyz が 1/2、6 コア分離が 1/2、[x,z,y,q] が 1/5 だった（2.3 節）。
- **期待効果**：raw 要求の削減。ただし速度は、変換、TCI 取得、壁面取り出し、stream/reflection、pivot 継承、次更新の費用まで含めて決まる。静的な要素数だけで改善を主張しない。
- **成立条件**：実場でも合成場と同じ方向に要素数が動くこと（仮説。README の cut 診断は xyz について同方向）。[x,z,y,q] では streaming の非局所化による rank 増大と round 費用、境界平面の再設計が要素数の削減を食わないこと（仮説）。
- **最小反証試験（単一保存状態）**：(a) 各配置で保存 F を同じ予算で TT-SVD し、要素数・raw 代理値が現行を下回らなければその配置を停止。(b) 下回った配置について stream+reflection を 1 回行い、rank 増大・round 費用・壁面取り出し費用を現行と比べる。(c) pivot 継承と history の作り直し費用を見積る。
- **停止条件**：(a) で現行を下回らない。(b) で stream 後の rank または費用が、要素数の削減分を打ち消す。
- **規模**：単一保存状態。提案3 と独立に進められる。

### 提案5：成立案一つの一更新と次更新

- **分類**：採用判定。
- **内容**：提案3・4 で門を通った案一つについて、保存 step2 から一更新を行い、既存の数値・finite・資源基準で受理できるか、pivot 継承と次更新の費用が増えないかを確認する。実取得数・raw 要求・一時容量・失敗候補込みの実秒を報告する。
- **停止条件**：受理不合格、または次更新の費用が現行 fixed を上回る。
- **規模**：単一保存状態からの 2 更新。

### 提案6：短い軌道と条件拡張

- **分類**：条件変更。契約不変。
- **内容**：一更新比較と累積 dense 軌道比較を分けた上で、見込みのある条件へ進む。(a) 現契約で 1 モード N128。(b) 4 モード N256。
- **事前に明示する予測**：cold/fixed、source 評価、検査、stream、history のどの項がどう変わるかを、提案1 の分解に基づいて試験前に書く。初版の「半分」「0.7 倍」は根拠が不足していたので使わない。
- **資源**：N256 は population 配列 1 本 432 MiB に加え、rank 25 の共有 suffix 14.06 MiB が現 8 MiB cap を超え、r₂=17 の xz supercore 約 1,003 万行が pair/workspace 上限を超える。配列容量とは別に、取得経路と workspace を含めた資源入場の確認が前提。
- **規模**：短い軌道（32 更新）。累積誤差・warm 発生率・壁 shear は現契約の全基準で確認する。

### 提案7：優先度を下げるもの

- **候補1（B 密 2 層・ledger の所属分離）**は精度・保証変更。提案2 で検査処理列を演算量に近づけた後に残る費用に対してのみ検討する。
- **R 省略、許容値緩和、finite 範囲縮小、検査の間引き**は提案しない。R 省略は合成場で契約と両立しなかった。実場では提案3 の試験 1 で同じ量を測れる。
- **quantics** は合成場で raw 代理値が現行 4 コア配置を上回り、採用根拠がない。
- **observer 台帳の大規模書換え、H2 平面評価**は根拠未確立のまま保留。
- **randomized rounding** は、提案3 で和の形成が避けられない場合の代替として温存する。

## 4. 方向性レビューの 3 問への回答（改訂）

### 問1：現契約を維持したとき、差を減らす見込みが最大の方向と、有望になる条件

fixed 更新では TCI 時間の 6〜7 割が検査区間で、構築側は dense の約半分である。したがって、契約を維持したまま差を減らす余地が最も大きいのは検査処理列（提案2）で、次に構築側の点取得を R 項に限る部分線形化（提案3）と配置の見直し（提案4）が並ぶ。ただし提案2 の削減幅は処理列計時の結果で決まり、提案3 は凍結基底の表現可能性という未検証で失敗機構のある仮説に依存し、提案4 は streaming 費用との交換になる。現時点で B 比が 1 を切る見込みを数値では述べない。

有望条件は、要求数比 r₁r₂/(9N_xN_y) が小さい方向、すなわち面内 N_x の増加と rank の低下である。流れは層流から遷移初期の低 Mach 流で、壁近傍に細かい構造を持たない場。発達乱流、fit 許容の緩和による改善、最適化 dense との比較は、同条件の計測がないので仮説にとどめる。

### 問2：局所改善を続けるか、表現・構築・計算法を変えるか、モデル近似を検討するか

- 局所改善は検査処理列（提案2）に集中する。取得経路の局所改善は、1 要求あたりの費用の内訳（提案1）が分かるまで新規投資を止める。
- 計算法変更は提案3 を単一状態の 4 試験で判定する。節約は投影経路でのみ生じることを前提に置く。
- 表現変更は提案4 を単一状態で判定する。合成場の結果から、paired xyz と 6 コア分離は現行局所 streaming を保つ候補、[x,z,y,q] は streaming 再設計を要する候補として扱う。
- モデル近似は検討しない。

## 付録B：記号

- N_raw：重複込み scalar 要求。paired 配置では 3N_x r₁ + 3N_z r₁r₂ + 3H r₂ + r₁² + r₂²。
- raw 代理値：TT の全コア要素数 + 内部 bond の r²。paired では N_raw に一致。
- D_q = Δf*_R：R 項が f* に与える population 寄与 (1/τ) w_q (4.5 c_qc_qᵀ:R − 1.5 tr R)。
- F_exact：完全 BGK target。P_B：前回受理 F の左右基底への射影。
- E_outside, E_Dfit, E_contraction, E_round：基底外誤差、D の fit 誤差、縮約誤差、丸め誤差。
