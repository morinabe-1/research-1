## 0. 要約

- **現在のN128・4モード・rank約25という条件は、点取得に基づくTCI構築がdenseと同程度の費用になる領域にある。** 取得点数は概ね「rank²×辺長の和」で決まり、現条件では全格子点の1〜2割を毎更新評価している。1点の評価はTT縮約と27方向のmoment計算を含むのでdenseの1格子点より高く、構築費用の下限はdense同程度になる。取得経路の局所改善を重ねても速度優位は出にくい。
- **検査区間だけでdenseの0.69倍（B）／1.39倍（C）を占める。** 契約を維持する限り、検査の実装効率が速度主張の前提になる。重要面1枚の検査が帯全体のdense更新の半分の時間を使っており、演算量の下限から1桁離れている可能性がある。
- **優位を狙う組み合わせは三つ。** (1) 格子点総数と「rank²×辺長の和」の比が大きい条件へ移る、(2) 衝突の線形部を点取得なしで組み立て、点取得をR項に限定する、(3) 契約を変えずに検査区間を演算量の下限へ近づける。
- **表現変更（添字順序・q因子化・quantics）の期待値は低い。** 合成場では、streamingを局所化するq因子化配置が要素数を1.6〜3.1倍に増やし、quanticsの要素数削減は1〜3割にとどまった。
- **モデル近似（R省略）は現契約と両立しない。** 合成場では、擾乱振幅が平均流の2.7%でもR項の寄与がfit予算の20倍を超えた。

## 1. 現状の読み方

### 1.1 費用の分解

READMEの共有後32更新の区間値から、検査区間と残りを分ける。

| 共有後32更新 | C | B |
|---|---:|---:|
| 検査区間合計 F選択・重要面 + P/H + ledger/kernel（秒） | 30.85 | 15.44 |
| 検査を除く残り fit・入力取得・補正・stream・history（秒） | 22.73 | 21.07 |
| 同範囲dense（秒） | 22.26 | 22.41 |
| 検査/dense | 1.39 | 0.69 |
| 残り/dense | 1.02 | 0.94 |

- 構築側の費用がゼロになっても、検査を現状のままにすればB比は0.69を下回らない。
- 検査を除いた残りがdenseとほぼ同じ。これは偶然ではなく取得点数の帰結と読める（1.2節）。
- READMEが注記する通り、区間値は総時間に内包されたもので、残りの内訳（fit本体・取得・補正・stream・history）は分からない。提案1の分解が必要。

### 1.2 取得点数の見積もり

fixed crossの取得点はコアごとのfiber数の和 Σ_k r_{k-1} n_k r_k で決まる。q最後の配置 [x, z, y, q] で bulk rank 25/17、辺長 128・128・32 とすると、空間点の評価数は

- x コア：128 × 25 = 3,200
- z コア：25 × 128 × 17 = 54,400
- y コア：17 × 32 × r₃（r₃ ≤ 27）= 最大 14,700

合計約7万点で、全52万格子点の1〜2割。各点でTT縮約により入力27方向を取り出し、moment と平衡分布を計算する。1点の費用はdenseの1格子点更新の数倍と見るのが自然で、積は dense 同程度になる。これが「残り/dense ≒ 1」の説明として最も単純である。この説明は仮説であり、提案1で検証する。

旧N128優位（層流・1モード、比0.27〜0.41）は rank が小さく取得割合が数%だったから、と読めば現在の結果と矛盾しない。契約差ではなく領域差が主因と考える。

### 1.3 有望条件の目安

取得点数 ≒ r²Σn、dense ≒ Πn·27 とし、1点あたり費用の定数を無視した余裕係数 (Πn/Σn)/r² を示す。

| 条件 | Πn/Σn | 余裕係数 |
|---|---:|---:|
| N128帯 128×32×128、rank 25（現在） | 1,820 | 2.9 |
| N128帯、rank 17 | 1,820 | 6.3 |
| N128帯、rank 10（1モード級） | 1,820 | 18 |
| N256帯 256×32×256、rank 25 | 3,855 | 6.2 |
| N512帯 512×32×512、rank 25 | 7,944 | 12.7 |

係数が10を超える領域でなければ、1点あたりの費用差を吸収して速度優位を示すのは難しい。面内の格子数を増やすか、rank の小さい場に限るかのどちらかである。帯の厚さ N_y=32 は Σn を小さく保つので有利だが、面検査の費用は N_x N_z に比例して増える。

### 1.4 dense基準の水準

denseは1更新約0.70秒で、2千万population/秒程度である。最適化されたC実装はこの1桁上を出す。TCI側も同じ言語環境なので比較は対等だが、最終的に主張できる優位は格子規模または1/rank に対する漸近的なものに限られ、定数倍の改善では主張が保てない。

## 2. 合成場によるTT診断（新規）

### 2.1 目的と限界

提案の前提のうち、保存状態がなくても確認できるものを、READMEと同じ形の合成場で篩にかけた。スクリプトは `scripts/toy_tt_rank_check.py`、生データは `docs/toy_tt_rank_results.json`。

- 格子：128×32×128、D3Q27、BGK τ=2.036。壁は y=0、帯は下壁から32層。
- 場：平均流 U(y) は半チャネル高さ128の放物線で U_max=0.05。擾乱は (k_x,k_z)=(1,1),(2,1),(1,2),(3,2) の4モード、phase 0、壁で消える y 形状。振幅 ε は u'/U の rms が 2.7%〜540% になるよう掃引。
- 分布：f = f_eq + f_neq（Chapman–Enskog一次）、f* = (1−1/τ)f + (1/τ)f_eq。
- 計測：TT-SVD で相対 Frobenius 1e-8 まで打ち切った rank・要素数。再構成誤差は全ケースで 1e-8 以下を確認。

**限界。** 元研究の場ではない（モード定義・振幅・位相・非平衡の構造が異なる）。TT-SVDは最適打ち切りで、TCIの rank はこれ以上になる。壁面補正・streaming・時間発展・計時は含まない。合成場の rank（最大16）は README の 25/17 より小さく、元研究の場はより多くの構造を持つ。したがって以下は仮説の篩であり、採否の根拠ではない。

### 2.2 R項の rank（提案3の前提）

配置 [x,z,y,q]、各量を f* と同じ絶対誤差予算 1e-8·‖f*‖ で打ち切る。「空間点数」は q コアを除く fiber 点数で、fixed cross の評価点数の代理。

| u'/U rms | ‖Δf*_R‖/‖f*‖ | f* の rank | f* 空間点数 | Δf*_R の rank | Δf*_R 空間点数 | 比 |
|---:|---:|---|---:|---|---:|---:|
| 2.7% | 2.3e-7 | 10/11/10 | 18,880 | 4/2/3 | 1,728 | 0.09 |
| 27% | 2.3e-5 | 11/13/10 | 23,872 | 6/4/6 | 4,608 | 0.19 |
| 81% | 2.0e-4 | 15/14/10 | 33,280 | 8/5/6 | 7,104 | 0.21 |
| 270% | 2.3e-3 | 16/14/10 | 35,200 | 10/5/6 | 8,640 | 0.25 |
| 540% | 9.6e-3 | 16/15/10 | 37,568 | 10/6/6 | 10,112 | 0.27 |

読み取り：

- **R項の cross は f* 全体の 1〜3割の点数で済む。** 擾乱が平均流の5倍でも 0.27 にとどまる。R は平均流と線形項を含まず、少数モードの二次積だけで構成されるためで、許容値の緩和よりも構造の寄与が大きい。
- **線形部 f*_lin の rank は f* とほぼ同じ。** 線形部は rank を担うが、q 縮約と y スケーリングで厳密に作れるので取得点を要しない。凍結基底への投影費用は Σn·r²·（項数）の規模。
- **R省略は現契約と両立しない。** u'/U=2.7% でも寄与が予算の20倍。ε² 則で外挿すると、省略が予算内に収まるのは u'/U ≲ 0.6% のときに限られる。
- q 側の bond rank は常に10で、これは ρ・j・Q の moment 数 1+3+6 と一致する。元研究の保存Fで q 側 rank を測れば、f が平衡多様体からどれだけ離れているかが分かる。

### 2.3 添字配置と因子化（提案5の前提）

f* を各配置で 1e-8 まで打ち切った要素数。dense は 14,155,776。

| 配置 | u'/U 27%：要素数 | 最大rank | u'/U 270%：要素数 | 最大rank |
|---|---:|---:|---:|---:|
| [x,z,y,q]（現行想定） | 24,142 | 13 | 35,470 | 16 |
| [x,y,z,q] | 57,166 | 34 | 91,918 | 50 |
| [x,z,y,qx,qy,qz]（q を末尾で因子化） | 24,115 | 13 | 35,443 | 16 |
| [x,qx,z,qz,y,qy]（streaming局所化） | 64,878 | 25 | 110,857 | 41 |
| [x,qx,y,qy,z,qz]（同） | 37,704 | 34 | 89,308 | 53 |
| quantics [x bits, z bits, y bits, q] | 17,006 | 36 | 31,500 | 56 |
| quantics [(x,z) bits 交互, y bits, q] | 58,234 | 76 | 138,012 | 129 |

読み取り：

- **添字順序の効果は場に依存する。** READMEの保存入力では xzy→xyz で core 要素が約半分になったが、合成場では逆に 2.4〜2.6 倍に増えた。順序変更の根拠は元研究の保存入力での診断に限り、一般化しない。
- **q を末尾で因子化するだけなら費用は増えない**が、streaming を隣接コア対の局所演算にするには q 成分を空間コアの隣へ置く必要があり、その配置は要素数を 1.6〜3.1 倍にした。streaming の節約がこの増加を上回る必要がある。
- **quantics の要素数削減は 1〜3 割**で、最大 rank は 2.7〜3.5 倍、コア数は 20 になる。少数モードの滑らかな場では採用根拠が薄い。(x,z) 交互配置は大きく悪化した。

## 3. 優先順位付き提案

各提案に、分類、期待効果、成立条件（確認済み／仮説）、最小の反証試験と停止条件、必要な試験規模（単一保存状態／短い軌道／累積軌道）を示す。

### 提案1：費用の下限分解

- **分類**：診断。
- **内容**：保存された step2 入力1件で、(a) 固有取得点数と重複込み scalar 要求数、(b) 1点あたりの TT 評価と平衡分布計算の演算量、(c) 重要面・P/H 検査の参照評価と metric の演算量、(d) stream・補正・history の演算量を数え、区間ごとの実秒と並べる。
- **期待効果**：直接の高速化はない。実測/下限の比が大きい区間は局所改善の対象、小さい区間は表現・計算法の変更でしか減らない、という切り分けができ、提案2〜5の採否を決める。1.2節の「残り ≒ dense は取得点数の帰結」という仮説もここで検証される。
- **成立条件**：なし。
- **停止条件**：なし。単一保存状態で完了する。

### 提案2：領域判定試験

- **分類**：条件変更。契約・検査・閾値は不変。
- **内容**：(a) 現契約で 1モード N128 を32更新。(b) 4モード N256（256×32×256）を短い軌道で。
- **期待効果**：(a) rank が半分以下になれば取得点数は 1/4 以下。B比が現4モードの半分未満になると予測する。(b) Πn/Σn が2.1倍になるので fit 区間が約半分、面検査は dense 比で不変、点検査は 1/4 と予測する。
- **成立条件**：1モード場の rank が4モードの半分以下（仮説。旧N128結果と整合）。N256 で rank が変わらない（仮説。同じ滑らかな場なら解像度を上げても rank は増えない）。
- **停止条件**：(a) で B比が現値の 0.7 倍を下回らない、または (b) で fit 区間が 0.7 倍を下回らないなら、取得点数モデルが誤り。提案3・5へ進む前に提案1へ戻る。
- **資源**：N256 の dense 配列は 1 本約 450MB で、RSS 1280MiB に対して 2 本で 7 割。資源契約の別登録が必要。
- **規模**：短い軌道（32更新）。

### 提案3：部分線形化と凍結基底への直接投影

- **分類**：計算法変更。モデル不変、契約不変。READMEの候補2に対応。
- **内容**：u₀ = U(y)e_x として Q = jjᵀ/ρ = −ρu₀u₀ᵀ + u₀jᵀ + ju₀ᵀ + R、R = (j−ρu₀)(j−ρu₀)ᵀ/ρ と分ける。線形部は q 方向の縮約（ρ, j）と y コアのスケーリング（U(y)）だけで作れるので rank 保存の厳密 TT 演算になる。前回受理Fの左右基底へ直接投影し、大きな sum/round を作らない。R だけを TCI（cross）で取得し、f* の絶対誤差予算から導いた許容値で打ち切る。
- **期待効果**：線形部の点取得がゼロになる。R の cross 点数は合成場で f* の 1〜3 割（2.2節）。構築側の取得費用を 3〜10 倍下げる余地がある。ただし検査区間は変わらないので、提案4と組み合わせないと B比 1 を切る見込みは立たない。
- **成立条件**：
  - 凍結基底が次更新の f* を fit 予算内で表せる：**同一軌道では確認済み**（fixed31 の成立は同じ性質を間接的に示す）。他の入力・位相・外力では仮説。
  - R の rank が f* より十分小さい：**合成場で支持**、元研究の場では仮説。
  - 正密度、U(y) ≠ 0：現場で確認済み。
  - 線形部の投影費用 Σn·r²·項数 が取得費用より小さい：見積もりのみ。
- **最小反証試験（単一保存状態）**：
  1. 保存入力から R を厳密に計算し、f* と同じ絶対予算で TT-SVD して rank r_R を測る。r_R が r の 0.7 倍以上なら停止。
  2. 線形部を凍結基底へ投影した結果と受理 F の差を全点で測り、基底外誤差が fit 1e-8 の予算を超えれば停止。
  3. 分割の代数照合（正密度・非零U・全速度成分を含む）が kernel 1e-14 を満たさなければ停止。
  4. R-cross + 投影 + 維持する検査の合計が、共有後Bの同入力・同範囲費用以上なら停止。
- **累積軌道で確認するもの**：基底外誤差の蓄積、warm 発生率、累積 velocity・壁 shear。32更新を現契約の全基準で通す。
- **規模**：単一保存状態で4試験、合格後に短い軌道。

### 提案4：検査区間の演算量下限化

- **分類**：局所改善。数式・対象点・閾値・頻度・独立性は不変。
- **内容**：B の F 区間は 1 更新あたり約 0.35 秒で、dense の全帯 1 更新 0.70 秒の半分。重要面 1 枚は帯の 1/32 の格子点しかないので、参照衝突・候補 TT の面評価・stress の演算量だけなら 1 更新あたり数十 ms が下限と見積もれる。実測がその 5 倍を超えていれば実装側の管理費であり、契約を変えずに削減できる。P/H 区間も同様に点数 256×3 と面 1 枚の演算量を下限とする。
- **期待効果**：B 総時間の最大 1/4〜1/3。C ではさらに大きい。
- **成立条件**：現在の検査実装が演算量の下限から大きく離れている（仮説。提案1で判定）。
- **停止条件**：提案1で実測/下限 ≤ 3 なら削減余地なしとして停止。
- **規模**：単一保存状態。削減後の数値一致は保存入力で全項目を照合する。

### 提案5：表現変更

- **分類**：表現変更。厳密、契約不変。
- **内容**：(a) xzy→xyz の添字順序、(b) q=27 を 3×3×3 に分けて各成分を対応する空間コアの隣に置く（streaming が隣接コア対の局所演算、反射が三つの反転の積になる）、(c) quantics。
- **期待効果**：(a) README の cut 診断では core 要素が約半分。(b)(c) は合成場で要素数が増えるか、削減が 1〜3 割にとどまった（2.3節）。
- **成立条件**：効果は場の相関構造に依存する。合成場で (a) が逆向きに出たことから、保存入力での診断だけを根拠にする。
- **最小反証試験（単一保存状態）**：保存 F を各形式で 1e-8 に TT-SVD し、要素数・rank・推定取得点数を現形式と比べる。現形式を下回らなければ停止。(a) は加えて実 TCI 1 更新の fit 時間と stream 時間を測る。(b) は stream+reflection の時間と rank 増大を単一状態で測り、要素数増加分を上回る節約がなければ停止。
- **注意**：いずれも pivot 継承、P/H 面の取り出し、history の作り直しが必要。提案2で領域の見込みが立ってから着手する。
- **規模**：単一保存状態。

### 提案6：優先度を下げるもの

- **候補1（B密2層・ledger の所属分離）**は精度・保証変更。検出能力を落として得る削減は、提案4で演算量の下限に近づけた後に残る費用に対してのみ検討する。
- **R 省略、許容値緩和、finite 範囲縮小、検査の間引き**は提案しない。R 省略は合成場で現契約と両立しなかった（2.2節）。
- **observer 台帳の大規模書換え、H2 平面評価**は根拠未確立のまま保留が妥当。
- **randomized rounding** は、提案3で基底外誤差が予算を超えた場合の代替（sum/round の費用を r³ から r²·r_target に下げる）として温存する。

## 4. 方向性レビューの3問への回答

### 問1：現契約を維持したとき、差を減らす見込みが最大の方向と、有望になる条件

差を減らす見込みが最大なのは提案3と提案4の組み合わせである。提案3は構築側の取得点を R 項に限定し、提案4は検査側を演算量の下限へ近づける。どちらか一方では B比 1 を切る見込みは立たない。N128・4モードで実際に 1 を切るかは r_R と検査下限の両方に依存し、現時点では見込みにすぎない。

有望条件は余裕係数 (Πn/Σn)/r² が 10 以上の領域である。具体的には面内 N が 256〜512 で rank 25 以下、または N128 で rank 10 以下。流れは層流から遷移初期の低 Mach 流で、壁近傍に細かい構造を持たない場。発達乱流は rank が上がるため現方式では見込みがない。精度条件については、fit 1e-8 の緩和は滑らかな場の rank を対数的にしか下げないので、緩和による改善は小さく、勧めない。

### 問2：局所改善を続けるか、表現・構築・計算法を変えるか、モデル近似を検討するか

- 局所改善は検査区間（提案4）に限って続ける。取得経路の局所改善は上限が dense 同程度なので新規投資を止める。
- 計算法変更は提案3を進める。費用の下げ幅は構築側の取得費用で 3〜10 倍（合成場に基づく見込み、元研究の場では未検証）。
- 表現変更は提案5を単一状態の篩にかけるが、合成場の結果から期待値は低い。
- モデル近似は検討しない。

### 問3：各提案を反証できる最小の観測と停止条件

| 提案 | 単一保存状態で棄却 | 短い軌道が必要 | 累積軌道・壁/粗密接続まで必要 |
|---|---|---|---|
| 1 下限分解 | 計測そのもの | | |
| 2 領域判定 | | B比・fit区間の予測との比較 | |
| 3 部分線形化 | r_R、基底外誤差、代数照合、費用門の4試験 | | 誤差蓄積、warm 発生率、壁 shear |

粗密閉ループは速度仮説の反証には不要で、採用後の妥当性門として扱う。各停止条件は試験前に固定し、結果後に基準を緩めない。

## 付録B：記号

- Πn：帯の格子点総数 N_x N_y N_z。Σn：辺長の和 N_x + N_y + N_z。
- r：TT の bulk rank。r_R：R 項を f* と同じ絶対予算で打ち切ったときの rank。
- Δf*_R：R 項が f* に与える寄与 (1/τ) w_q (4.5 c_qc_qᵀ:R − 1.5 tr R)。
- 余裕係数：(Πn/Σn)/r²。取得点数 ≒ r²Σn と dense ≒ Πn の比から定数を除いたもの。
